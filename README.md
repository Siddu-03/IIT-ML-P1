# HPC Backdoor Detection

A Hardware Performance Counter (HPC)-based approach to detecting potential backdoor attacks through statistical analysis of CPU performance metrics and anomaly detection.

## Overview

This project focuses on identifying unusual execution patterns through the analysis of hardware performance counters.

## Key Components

- HPC trace preprocessing
- Feature extraction
- Statistical anomaly detection
- Machine learning-based detection
- Anomaly scoring and classification

## Project Structure

- `src/` – Core implementation
- `models/` – Detection model
- `requirements.txt` – Project dependencies
- `report.pdf` – Technical documentation

## Objective

To explore hardware performance counter analysis as a method for identifying potential backdoor activity in program execution.
